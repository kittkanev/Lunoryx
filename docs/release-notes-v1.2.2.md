# Lunoryx Studio 1.2.2

Исправления безопасности и надёжности по аудиту версии 1.2.1.

- Lua работает в песочнице: текстовые скрипты, лимит памяти 256 МиБ, общий лимит инструкций для корутин, защита от обхода через pcall/xpcall и ограничения тяжёлых строковых операций. Системные библиотеки и пользовательские финализаторы отключены.
- Пути ресурсов проекта ограничены его папкой; Lua/MCP — рабочей папкой. Запрещены сетевые и служебные пути, выход через символические ссылки. Внешние ресурсы, выбранные в редакторе, встраиваются при сохранении.
- Встроенные изображения и звуки сохраняются компактно в base64. Чтение старых числовых массивов поддерживается; старые версии редактора не читают новые бинарные поля.
- Экспорт GLB и сохранение используют безопасные временные файлы. Повторные текстуры экспортируются и упаковываются один раз.
- Пакет игры проверяется без чтения всего EXE. Поддержано расположение футера перед таблицей сертификатов PE; пустая настройка иконки сохраняет стандартную иконку.
- Исправлены UTF-8 в MCP, вывод предыдущих команд, пути аудио Windows, drag-and-drop, ограничения трансформаций и числа объектов, неизвестные примитивы, F5, пустой аудио-ID, счётчик ID при отказе загрузки и коллинеарные полигоны.
- Несохранённый проект автоматически получает отдельный снимок `.autosave.lunoryx` раз в минуту вне Play. Для восстановления используйте **Open recovery** и Save As.
- Windows-зависимости обновлены до Lua 5.4.8 и SDL 2.32.10. Тестовые хуки вынесены в отдельную сборку, добавлены флаги защиты бинарников. CI закреплён по SHA, опубликованные релизы не перезаписываются, новые файлы получают аттестацию происхождения.

Локально прошли интеграционные тесты, проверки Lua/MCP, геометрии, Rust, физики и аудио, ASan/UBSan/LeakSanitizer для интеграционного модуля, игровой сценарий с удалёнными исходными ресурсами и валидатор glTF без ошибок и предупреждений. Windows EXE собран MinGW и проверен на флаги защиты и внешние DLL; публикация дополнительно зависит от штатных проверок CI на Windows.

Полный разбор исправлений, совместимости, проверок и оставшихся ограничений: [AUDIT-REMEDIATION.md](https://github.com/kittkanev/Lunoryx/blob/main/docs/AUDIT-REMEDIATION.md). Подписание Authenticode, полный аудит зависимостей и изменение архитектуры физики не заявляются завершёнными.
