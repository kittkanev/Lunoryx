# Lunoryx Studio 1.0.1 — мини-патч надёжности

Исправления для первого стабильного выпуска. Тема, докинг и расположение панелей сохранены. Формат проекта и Lua API остаются совместимыми с 1.0.0.

## Что исправлено

- **Сохранение во время Play.** В 1.0.0 Ctrl+S мог записать временное игровое состояние поверх проекта. Теперь Save / Save As недоступны до Stop; вызов через MCP также возвращает ошибку. Существующий файл и признак сохранённости не меняются. После Stop можно сохранить сцену редактора.
- **Повреждённые числа в проекте.** Слишком большие индексы, дроби и отрицательные значения больше не превращаются в другие вершины, слоты материалов или байты текстур/звука. Проверка выполняется до сужения типа. Проверяются также целочисленные настройки, идентификаторы и параметры модификаторов. При ошибке открытая сцена сохраняется.
- **Невалидная геометрия.** Отбрасываются нечисловые UV и некорректные цвета. Будущий объём треугольников проверяется до триангуляции загружаемого меша.
- **Контейнер игры.** Весь манифест проверяется до копирования ресурсов. Перекрывающиеся диапазоны отклоняются: повторное использование одного большого блока больше не вызывает многократного выделения памяти. Ограничена вложенность JSON; упаковщик и runtime одинаково отклоняют неоднозначные имена ресурсов.
- **Отчёт релиза.** В REPORT.md автоматически записываются точный SHA сборки и ссылка на прошедший CI.

## Проверки

- Регрессионные тесты сохранения Play, целостности старого файла и восстановления после Stop.
- Повреждённые schema 1/2 проекты, переполнение и дробные индексы, байты за пределами 0–255, неверные ID и игровые настройки; отказ без замены текущего документа.
- Невалидные цвета/UV и предварительный контроль бюджета триангуляции.
- Контейнеры с корректной CRC, но неверными диапазонами, перекрытием, дубликатами, обходом пути и глубокой вложенностью. Корректные ресурсы в обратном порядке и пустые диапазоны продолжают читаться.
- Полный CI: Linux/MinGW с -Werror, нативные Windows-тесты, ASan/UBSan/LeakSanitizer, Lua/MCP, аудиокодеки, Khronos GLB Validator и прохождение самостоятельной игры на Windows/Mesa и Linux/Mesa.

## Файлы и ограничения

`Lunoryx.exe` — Windows x64 редактор; ZIP — редактор, примеры, инструкции и лицензии; `GemTrail.exe` — самостоятельная игра. Контрольные суммы находятся в `SHA256SUMS.txt`.

Требуются OpenGL 2.1 compatibility и FBO. Физика AABB, статический GLB; риг, нодовые системы и офлайн-рендер остаются дальнейшим развитием. Lua-скрипты доверенные и имеют доступ к файлам/процессам. Корректные старые контейнеры и проекты читаются; повреждённые данные, которые раньше молча исправлялись преобразованием чисел, теперь отклоняются с сообщением в Output. Windows/Mesa не охватывает все пользовательские GPU.
