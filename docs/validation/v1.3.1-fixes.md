# Lunoryx 1.3.1 — Gemini Argon fixes

Scope: the nine file groups in the supplied audit/refactoring specification. Existing published releases are immutable. Publication requires the complete successful native CI run for the exact tagged commit.

1. **Viewport ownership:** existing Resize already reused GL IDs, restored bindings, checked completeness and fell back from HDR. Added noncopyable RAII, initialization-failure cleanup, and immediate post-attachment release when disabled. Native GL tests resize 100 times, toggle post/HDR 50 times, query deleted IDs and verify scoped destruction. This validates object lifetimes, not every driver's VRAM accounting.
2. **Texture uploads:** preallocate/reuse two mip buffers, guard texture ownership through cache insertion, delete failed uploads, zero their accounting, saturate eviction subtraction. Existing ClearStudioTextures is called on successful load/new/sample project transitions. Native GL tests inject bad_alloc during upload and verify deletion, zero accounting and successful subsequent upload.
3. **Audio editing:** Replace/Remove explicitly stop and unload voices. Full-length Lua strings reject NUL/control bytes before path resolution; shared local-path validation and MCP/project sound-name checks cover sibling inputs. UTF-8, spaces, default/empty names and future in-project references remain valid. No directory-confinement escape was demonstrated in the old code; the confirmed defect was input truncation.
4. **Stop lifecycle:** unload all backend voices independently of physics state, including voices absent from the current sound list; clear play snapshots after edit-state restoration. Regression loads ten real WAV clips, tests preview Stop, repeated Play/Stop and an orphaned voice, asserting zero live voices afterward.
5. **Dirty state:** normalize signed zero and non-finite float hash inputs; string lengths use uint64_t. Camera/widget/color signed-zero changes preserve ProjectDirty, and a real text edit changes it.
6. **Bounds:** NaN/±Inf in any vertex coordinate produce invalid local/world bounds. Finite and mirrored geometry continue to work.
7. **Package offsets:** _fseeki64/_ftelli64 on Windows and fseeko/ftello on POSIX; absolute read positions remain uint64_t, checked by subtraction before allocation/seeking. Native tests read a tiny valid package after a sparse >3 GiB prefix, reject UINT64_MAX offsets transactionally, and retain runtime/payload budgets and existing Authenticode coverage. The normal writer's bounded output did not itself exceed 2 GiB.
8. **Manual generation:** reject the GUIDE terminator and incomplete code fences before writing any output, including a bad later RU/EN topic. Lists use ul/li; quotes, backslashes, Unicode and code samples remain intact. This is a repository-content/build-time boundary, not a remote runtime exploit.
9. **macOS packaging:** validate every Mach-O in the app, including managed runtime native libraries; allow system libraries and resolvable in-bundle loader/executable/rpath dependencies, reject arbitrary external absolute paths, traversal and missing dependencies before signing. Clear iconset before/after generation and fail explicitly on a malformed version macro. Linux policy tests supplement actual ARM64/Intel packaging, runtime and universal-app CI checks.

Verification commands: python tools/test_release_safety.py; python tools/build_manual.py; make test test-integration test-postprocess test-render; existing native Windows/macOS integration, packaged-game, rendering and managed-worker checks; existing Linux AddressSanitizer/UndefinedBehaviorSanitizer/leak checks. The published HTML report links the successful source run and contains its fresh UI video and parser-soak evidence.

Limits: Linux is GCC, Windows is MinGW GCC, macOS is Apple Clang. MSVC is not a supported build configuration and was not claimed tested. There is no Apple Developer ID/notarization or Windows publisher certificate. Finite regression runs do not prove zero vulnerabilities or exhaustive driver/resource behavior.
