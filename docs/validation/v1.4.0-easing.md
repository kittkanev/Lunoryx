# P1 easing curves / Кривые easing

Schema 4 adds Quad in/out/in-out, Cubic in/out/in-out and Sine in-out to existing Linear/Smooth/Step. IDs 0–2 retain their meaning. The C17 sampler, animation editor, Luaryx `animation_key`, project validation, history and packed game use the same curve IDs. Legacy schemas reject new IDs. / Schema 4 добавляет квадратичные, кубические и синусоидальную кривые. C17, таймлайн, Lua, сохранение, Undo и отдельная игра используют одинаковые ID; значения 0–2 сохраняют смысл.

This completes a bounded easing implementation, not skeletal animation, IK, blending, events, root motion or custom Bezier authoring. Continuous curves are monotone and bounded by endpoint values. Rotation still uses shortest angular interpolation. / Это реализация easing, а не скелетов, IK, блендинга, событий, root motion или редактора произвольных Bezier-кривых.
