Lunoryx Studio 1.3.0 adds real C# scripting through a self-contained .NET/Roslyn worker, interoperable Lua/Luaryx entity/property/message APIs, project folders and a startup project selector. Explorer creates normal and module scripts in both languages; the code editor includes highlighting, line numbers, undo and compiler diagnostics.

Native Windows x64 and universal macOS applications are packaged with their managed runtimes. README is available in English and Russian with the requested platform logos. Engine licensing is GPL-3.0-only; third-party terms are preserved.

Audit repairs include pinned asset access, parser budgets, isolated native tasks, explicit MCP capabilities, complete bounded trigger state, spatial physics and static collision sweeps, Play-safe recovery, streaming game packages and bounded caches. The HTML report maps all 40 audit items to changes, evidence and remaining limits.

**Exactly four uploaded assets:** Windows ZIP, universal macOS ZIP, Verification.mp4 and Audit-report.html. Archives include licenses, SBOM and checksums. Keep Runtime beside the Windows executable.

C# has the OS permissions of the user and requires trust for loaded projects. Windows has no publisher signature; macOS is ad-hoc signed and is not Apple-notarized. Signing certificates and exhaustive GPU/driver coverage are not available. CRC32 game containers are corruption checks, not authentication. See the report for the finite validation scope.
