# Platform marks

Platform identification artwork matching the Linux (Tux), Windows and macOS (Finder) references supplied by the project owner. The inline chat originals were not exposed as downloadable files in this workspace; these copies come from the following published originals:

- [Tux](https://commons.wikimedia.org/wiki/File:Tux.png), Larry Ewing / Simon Budig / Anja Gerwinski. Permission to use/modify granted with acknowledgement.
- [Windows 2012 logo](https://commons.wikimedia.org/wiki/File:Windows_logo_-_2012.svg), Microsoft; simple geometric mark.
- [Finder, macOS Yosemite](https://commons.wikimedia.org/wiki/File:Finder_icon_macOS_Yosemite.png), Apple; platform identification.

Platform names and marks belong to their respective owners. They do not imply endorsement and are not relicensed under the engine's GPL license.
